# YUNU_GAME
아이와 셀프 게임 제작용

## 🧱 레고 시티 — 오픈월드 브릭 사냥

사진 한 장(레고 시티 디오라마 1인칭 시점)을 3D로 옮긴 뒤, 그 도시를 **안전지대**로 삼는
**1인칭 오픈월드 사냥 게임**. 웨이브는 없다. 흙길을 따라 걸어 나가 사냥터를 골라 사냥한다.

세상은 **가로 7000 · 세로 7000 스터드**, 지역이 **40곳**이다.
도시를 가운데 두고 네 겹의 고리로 펼쳐지고, 흙길이 도시 여덟 성문에서 바깥으로 이어진다.

| 고리 | 지역 |
| --- | --- |
| 🏙️ 가운데 | **레고 시티**(안전지대) |
| 첫째 (900) | 좀비 마을 · 가을 숲 · 봄 들판 · 늪지대 폐가 · 여름 해변 · 폐광 · 깊은 동굴 협곡 · 겨울 설원 |
| 둘째 (1700) | 높은 산 · 사막 지대 · 바다/부두 · 오염 지대 · 하수도 · 자수정 동굴 · 금광 · 점적석 동굴 |
| 셋째 (2500) | 전파 관제소 · 전파 통제 불가 구역 · 용암 지대 · 피라미드 유적 · 무인도 · 폐쇄된 바다 · 폐쇄된 공연장 · 유령 미술관 · 귀신의 집 · 방사능 연구소 · 폐쇄된 좀비 연구소 · 화재 감염 연구소 · 석탄광 · 다이아몬드광 · 좀비 폐쇄 구역 |
| 넷째 (3300) | **1 · 3 · 13 · 75 · 81 · 92 · 98 · 103 구역** |

지형은 `src/biomes.js` 의 공식(모래언덕 · 분지 · 봉우리 · 협곡 · 대지 · 구덩이 · 섬 · 용암밭)으로
찍어내고, 지역 내용물은 `src/regionKits.js` 의 빌더 열셋이 매개변수로 조립한다.
그래서 지역을 하나 더 넣으려면 `world.js` 표에 한 줄만 쓰면 된다.

사냥터 사이 들판에는 나무·바위·덤불이 지역 성격에 맞춰 흩뿌려지고(`src/wilds.js`),
멀리 있는 지형은 24 스터드 큰 판으로 지평선까지 이어져 **산이 들판에서도 보인다**.

### 실행

- **아이용**: `index.html` 을 더블클릭 (인터넷 없어도 됨. three.js 를 저장소에 같이 넣어두었다)
- 개발/검증: `node scripts/smoke.mjs` (playwright 필요 — 콘솔 오류·조작·웨이브·드로우콜을 한 번에 확인)

### 손에 무엇을 드는가 (핵심 규칙)

| 손 | 무엇 | 목록 | 키 | 쓰는 법 |
| --- | --- | --- | --- | --- |
| ✋ **오른손** | **무기** | 🗡️ 검 · 🔫 총 · 💣 폭탄 | `1` `2` `3` | 마우스 **왼쪽 클릭** |
| 📜 **왼손** | **두루마리 스킬** | 🐲 드래곤 파이어 · ☄️ 메테오 · 🔥 파이어볼 | `4` `5` `6` | 마우스 **오른쪽 클릭** 또는 `Space` |

- 무기는 오른손에 **직접 쥔다** (검·총·폭탄 모두 노란 미니피그 손에 들린다).
- 스킬은 왼손에 **두루마리(스크롤) 형태로 장착**된다. 시전하면 두루마리가 펼쳐지고
  문양이 빛나며, 드래곤 파이어는 브릭 드래곤 머리가 나타나 불을 뿜는다.

### 조작

| 키 | 동작 |
| --- | --- |
| `W A S D` | 이동 |
| `Shift` | 달리기 |
| `Space` | 점프 |
| 마우스 이동 | 둘러보기 (화면 클릭 시 마우스 잠금) |
| 마우스 왼쪽 | 오른손 무기 공격 |
| 마우스 오른쪽 / `F` | 왼손 두루마리 시전 |
| 마우스 휠 / `Q` | 오른손 무기 바꾸기 |
| `E` | 왼손 두루마리 바꾸기 |
| `T` | 표지판 앞에서 빠른 이동 (한 번 걸어가 본 곳만) |
| `Esc` | 잠깐 멈춤 (기록 확인) |
| 폰 | 왼쪽 조이스틱 이동 · 화면 드래그 시선 · ✋ 공격 · 📜 시전 · ⤴ 점프 |

화면 오른쪽 위 나침반이 **레고 시티(집)가 어느 쪽인지**와 거리를 알려준다.

### 규칙

- 상대는 전부 **브릭으로 만든 것**이다: 브릭 슬라임 · 브릭 좀비(낡은 브릭을 끼워 만든 인형) ·
  독 슬라임 · 방사능 슬라임 · 도깨비불 · 브릭 유령 · 화염 귀신 · 브릭 배트 · 경비 드론(기계) ·
  브릭 골렘 · 모래 골렘 · 크리스탈 골렘 · 얼음 골렘, 그리고 지역마다 다른 보스.
- 쓰러지면 피가 아니라 **브릭 조각**으로 팝 하고 흩어지며 스터드를 떨어뜨린다.
  노란 스터드 = 마나, 파란 스터드 = 총알·폭탄, 빨간 하트 = 체력 회복.
- **시민 미니피그는 공격 대상이 아니다.** 몬스터가 가까이 오면 도망친다 — 지켜야 하는 쪽이다.
- 사냥터마다 몬스터가 정해진 수만큼 계속 돌아다니고, 안쪽 깊은 곳에는 보스가 있다.
- 하트를 다 잃으면 쓰러져 도시에서 다시 깨어난다(게임 오버 없음). 최고 점수는 브라우저에 저장된다.

### 파일 구조

| 경로 | 역할 |
| --- | --- |
| `index.html` | HUD 마크업 + 스크립트 로드 순서 |
| `src/style.css` | HUD·시작/종료 화면 스타일 |
| `src/bricks.js` | 브릭 부품 공장(색 팔레트·스터드 텍스처·플레이트·손) |
| `src/loadout.js` | **무기/스킬 정본 표** (수치를 바꾸려면 여기) |
| `src/minifig.js` | 미니피그(시민·경찰) 조립 + 걷기 |
| `src/city.js` | 사진 속 도시 조립(도로·경찰서·연립주택·크레인·헬리콥터·차·나무) |
| `src/terrain.js` | 브릭을 계단처럼 쌓는 지형 + 청크 스트리밍 + 높이 질의 |
| `src/world.js` | **오픈월드 정본**: 지역 위치·지형 함수·흙길·출현표·분위기·빠른 이동 |
| `src/wilds.js` | 들판에 나무·바위·덤불 흩뿌리기(플레이어 주변만) |
| `src/weather.js` | 지역 입자: 설산 눈 · 늪 반딧불 · 동굴 먼지 |
| `src/places.js` | 사냥터 공용 부품(죽은 나무·판자벽·우물·크리스탈·광차 …) |
| `src/biomes.js` | 지형 공식·색 팔레트·분위기 프리셋 (지역 표가 불러 쓴다) |
| `src/regions.js` | 손으로 지은 사냥터 넷(좀비 마을·늪 폐가·동굴 협곡·높은 산) |
| `src/regionKits.js` | 매개변수로 찍어내는 빌더 13종(숲·해변·사막·바다·섬·용암·피라미드·광산·시설·하수도·공연장·미술관·귀신의 집) |
| `src/places2.js` | 새 지역용 부품(야자수·선인장·등대·난파선·콘크리트 벽·방폭문·콘솔·탱크·경고판·용암 웅덩이·액자·조각상 …) |
| `src/postfx.js` | 접사 심도 흐림 · 비네팅 후처리 |
| `src/hands.js` | 1인칭 두 팔 — 오른손 무기 · 왼손 두루마리 |
| `src/fx.js` | 발사체·폭발·브릭 파편·불꽃·스터드 (전부 풀링) |
| `src/enemies.js` | 브릭 몬스터 4종 + 웨이브 |
| `src/audio.js` | WebAudio 즉석 합성 효과음(에셋 파일 없음) |
| `src/hud.js` | DOM HUD 갱신 |
| `src/input.js` | 키보드·마우스(포인터 락)·터치 |
| `src/game.js` | 지휘자: 루프·전투 규칙·렌더 2패스 |
| `vendor/three.min.js` | three.js r150.1 (UMD, MIT — `vendor/three-LICENSE.txt`) |
| `scripts/smoke.mjs` | 브라우저 스모크 테스트 + 스크린샷 |
