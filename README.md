# YUNU_GAME
아이와 셀프 게임 제작용

## 🌀 손으로 그리는 미로 — `index.html`

`index.html`을 브라우저로 열면 바로 실행됩니다. (설치 필요 없음)

**규칙**
- 초록색 **시작**(왼쪽 위)에서 손가락이나 마우스로 끌어 빨간색 **도착**(오른쪽 아래)까지 가면 통과!
- 손이 지나간 자리는 **검은색 선**으로 그려집니다.
- **검은색 벽은 넘어갈 수 없습니다.** 벽에 닿으면 거기서 멈춥니다.

**기능**
- 난이도 4단계 (8×8 / 12×12 / 16×16 / 22×22) — 고를 때마다 새 미로 생성
- `새 미로` 새로 만들기 · `다시 그리기` 선만 지우기 · `정답 보기` 힌트 경로 표시
- 걸린 시간과 난이도별 최고기록 저장, 벽에 막힌 횟수 표시
- 휴대폰·태블릿 터치 지원, 화면 크기에 맞춰 자동 조정

미로는 매번 새로 만들어지며 **항상 풀 수 있는 미로**만 생성됩니다.
