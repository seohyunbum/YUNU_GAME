# 마피아 게임

가족과 함께 즐기는 9인 역할 기반 사회 추리 웹게임입니다. 시민팀, 마피아팀, 교주팀이
밤의 비밀 행동과 낮의 토론·투표로 마지막 승리를 겨룹니다.

## 주요 기능

- 솔로: 사람 1명 + 규칙 기반 AI 8명
- 온라인 듀오: 6자리 방 코드로 두 사람이 같은 진영이 되어 플레이
- 3개 진영과 5개 역할: 시민, 일반 마피아, 폭탄마, 교주, 신도
- 일반 마피아의 시민 외형 변신, 폭탄마의 최후 폭발, 교주의 1회 포교
- 모든 캐릭터 HP 2, 낮 투표는 피해 1, 밤 살해는 즉사
- 설치형 AI나 외부 API 없이 브라우저에서 동작

## 로컬 실행

```powershell
npm.cmd install
npm.cmd run dev
```

표시되는 주소를 브라우저에서 엽니다. 전체 검증은 `npm.cmd run verify`로 실행합니다.

## 온라인 듀오

방장이 6자리 코드를 만들고 상대가 같은 사이트에서 코드를 입력합니다. WebRTC P2P
방식이라 별도 회원가입이나 게임 서버가 필요하지 않습니다. 방장 브라우저가 전체 게임
상태와 AI를 관리하는 가족용 신뢰 모델입니다.
