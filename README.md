# 마피아 게임 (Mafia Game)

아이와 셀프 게임 제작용 저장소. 현재 프로젝트: **마피아 게임**.

솔로/듀오 모드, 시작 즉시 역할 배정, 마피아의 **변신** 스킬과 **폭탄마**, 제3세력 **교주팀**이
얽히는 역할 기반 심리 게임.

## 현재 상태

**설계 초안(v0.1) 단계.** 코드는 아직 없다. 확정된 규칙과 미정 항목은
[`docs/DESIGN.md`](docs/DESIGN.md) 가 정본이며, 밸런스 수치 초안은 [`data/`](data/) 에 있다.

- ✅ 확정: 모드 선택(솔로/듀오), 시작 즉시 역할 배정, 전원 최초 HP 2,
  일반 마피아의 밤 살해 + 아침 변신, 마피아 승리 조건
- ⬜ 후속 설계 대기: 폭탄마 상세, 시민 직업들, 교주팀, 인원 구성, 플랫폼

다음 설계 입력을 받기 전에 답이 필요한 항목은
[`docs/DESIGN.md` §10 미해결 질문](docs/DESIGN.md#10-미해결-질문--다음-설계-입력-때-답변-필요)에 번호로 정리해 두었다.

## 문서

| 문서 | 역할 |
|---|---|
| [`docs/DESIGN.md`](docs/DESIGN.md) | 게임 설계 정본 (규칙·데이터 모델·턴 흐름·미해결 질문) |
| [`data/roles.json`](data/roles.json) | 역할 정의 초안 (확정 수치만 기록, 미정은 `null`) |
| [`data/rules.json`](data/rules.json) | 전역 규칙 수치 초안 |

## 저장소 위치 안내

새 저장소를 만든 뒤에는 remote만 교체하면 그대로 이전된다.
