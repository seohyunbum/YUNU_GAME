# 세계정복 UI/UX 설계 (v1) — 턴 흐름·거점 화면·레이어

> **작성 계기**: 사용자 피드백 — "내 턴이 어떻게 끝나는지 모르겠음 / 턴 종료하면 상대가 뭘 하는지 모르겠음 /
> 어떻게 흘러가는지 전혀 직관적이지 않음 / 상점 창에 겹쳐 가려짐 / 거점은 **건물을 클릭하면** 그 메뉴가 나오게 하라 /
> 기본 UI·UX 하나하나 지적받지 말고 **설계부터 각 잡고 구현하라**" (2026-07-17)
>
> 규칙: 게임 규칙 정본 = [`../GAME_DESIGN_SPEC.md`](../GAME_DESIGN_SPEC.md). 작업 절차 = [`ue5-client-workflow.md`](ue5-client-workflow.md).
> **본 문서는 스펙에 없는 규칙(행동력 등)을 발명하지 않는다.**

## 0. 확정 사실 (설계의 바닥 — 코드·스펙 대조 완료 2026-07-17)

| 사실 | 근거 | UX 함의 |
|---|---|---|
| **행동 포인트 없음.** 자원이 되는 한 명령 자유, `턴 종료`로만 진행 | 스펙 §2.2 | "소진 미터"를 만들 수 없다 → 다른 장치로 전달해야 함 |
| 턴당 캡은 **초빙 10회 하나뿐** | `max_summons_per_turn` | 유일하게 "남은 횟수"를 셀 수 있는 명령 |
| 턴 순서 = 수입 → P1 → P2 → AI세력 → 해결(이동·전투) → 이벤트 → 승리판정 | 스펙 §2.2 | 내 턴 뒤에 무슨 일이 벌어지는지 = 이 4단계 |
| **Core 이벤트 13종** 발행 (TurnStarted·ProvinceCaptured·BattleEnded·Duel*·CharacterJoined·ProvinceRebelled·AllianceFormed·TechLevelUp·SkillExecuted·CutsceneTriggered·GameEnded·SaveLoaded) | `GameEvent.Of()` 전수 | **턴 리포트 재료 확보 — 신규 이벤트 불필요** |
| 시설 **6종 전부 건설 가능** (market·farm·port·academy·barracks·walls) | `game_rules.json` | 거점 화면이 6종을 다 다뤄야 함 |
| **민심(PublicOrder)·반란 구현됨** | `InternalAffairsManager` | 경고 UI 가능 |
| **이 게임은 대전이 아니라 협동** — 동맹 시야 공유 [MUST], 핫시트 = "같이 보는 화면", 아들 궁극기를 아빠가 봐줘야 함 | 스펙 §1.1·§1.2·§2.7 | **상대에게 정보를 숨기지 않는다.** 리포트는 같이 본다 |
| 초빙은 **세력 명령** (노드 인자 없음, 천명·pity 가 세력 단위) | `SummonOnce()` → `SendVerb("summon")` | 거점이 아니라 **지도**에 둔다 |
| 징병·건설은 **지도에서 노드 선택 후 2클릭**으로 이미 가능 | `RecruitSelected`/`BuildSelected` = `SelectedNodeId` | 거점으로 옮기면 **2→4클릭 퇴보** |
| 서버가 [4]~[1]을 **한 응답에 원자 처리**, 클라는 중간 페이즈 관측 불가 | `case "end": AdvancePhase(); DriveToInput();` | **페이즈 진행 애니메이션은 가짜** → 만들지 않는다 |

> 위 표는 설계안 v0 의 적대 검증에서 **코드를 열어 확인**한 결과다. 검증 자체도 배포 구사본을 읽어 3건(이벤트 수·민심·시설)을 틀렸으므로, **항상 워크트리 기준으로 대조한다** [MUST].

## 3. 턴 흐름 전달 (#1·#3)

### 3.1 "행동력 없음" 을 자명하게 — 미터 대신 **한 일 로그**

행동력이 없으므로 "남은 기회 체크리스트"는 **절대 비지 않는다**(징병·건설은 자원만 되면 무한). 비지 않는 체크리스트는
매 턴 "아직 할 일 있음" 경고를 띄워 초등학생에게 모달을 강요한다 → **방향을 뒤집는다.**

- 좌측 상시 패널 = **「이번 달에 한 일」**(누적 로그). 턴 시작 시 자연히 비어 있고, 명령할 때마다 한 줄씩 쌓인다.
- 소진을 셀 수 있는 유일한 것 = **초빙 `7/10`** → 그 카운터만 표시.
- 상단 자원 hover 툴팁: **"쓸 게 있으면 얼마든지 명령할 수 있어요. 횟수 제한은 없어요."** (초빙만 한 달에 10번)

### 3.2 현재 차례 표시 (P0 — 비용 0에 가까움)

페이즈 7칩 레일은 **만들지 않는다** (서버가 원자 처리라 중간 관측 불가 → 가짜 애니메이션).
대신 이미 있는 `UiTurnText()` 를 확장:

```
3턴 · 👤 아빠 차례   (다음: 👦 아들 → 🤖 다른 나라 → ⚔️ 싸움 판정)
```

### 3.3 턴 종료 버튼 — 유일·고정·비차단

- **우하단 단독 배치.** 현재 이웃(★무장 초빙·저장·이어하기)을 치운다 → 초빙은 지도 좌측 세력 명령, 저장·이어하기는 ⚙.
- **절대 차단하지 않는다** (Civ6 하드 블로킹 = 최다 불만).
- 확인 모달 1회 — 내용은 **"내가 한 일 + 남은 자원 + 되돌릴 수 없음"**. "아직 할 수 있는 일" 블록은 넣지 않는다(§3.1).

```
┌──────────────────────────────────┐
│ 이번 달을 끝낼까요?               │
│  내가 한 일                       │
│   · 병사 모으기 2번               │
│   · 시장 짓기 (한성)              │
│  남은 것: 금 5,000 · 식량 3,000   │
│  ⚠ 끝내면 이번 달 명령은 못 바꿔요│
│      [더 할래요] [이번 달 끝내기] │
└──────────────────────────────────┘
```
기본 포커스 = **[더 할래요]**. 민심 20 미만 거점이 있으면 상단에 한 줄 경고 추가.

## 4. 턴 리포트 (#2) — "상대가 뭘 했는지"

- **턴당 1회, [2] 진입 직전, 둘이 같이 본다** (스펙 §2.7 "같이 보는 화면"). 관점별 2회 재생·정보 차단 없음(P-4).
- 재료 = 기존 이벤트 13종. 신규 발행 불필요.
- **빈 섹션은 숨긴다.** 전부 0건이면 모달 대신 토스트 한 줄(`조용한 한 달이었어요`).

| 섹션 | 소스 이벤트 | 문구 예시 |
|---|---|---|
| 💰 벌이 | TurnStarted 스냅샷 차분 | `금 +1,200 · 식량 +800` |
| ⚔️ 싸움 | BattleEnded · DuelStarted/Ended · SkillExecuted · ProvinceCaptured | `위나라가 하비를 빼앗았어요.` / `장비 vs 하후돈 — 장비가 이겼어요!` |
| 🤝 다른 나라 | AllianceFormed · CharacterJoined · TechLevelUp · CutsceneTriggered | `오나라와 촉나라가 손을 잡았어요.` |
| 🏠 내 땅 | ProvinceRebelled · 재해 | `⚠ 성도에서 반란이 일어났어요!` |

- 행 클릭 = 리포트 닫고 **해당 거점으로 카메라 이동**. AI 턴 카메라 추적 시퀀스는 만들지 않는다(Total War 실패 사례).
- [건너뛰기] 허용 — 단 전문은 **[이력] 패널에 보존**되어 다시 볼 수 있다(스킵이 손실이 아니게).

## 5. 거점 화면 (#4·#5) — 건물 클릭 → 그 패널 하나

### 5.1 폐기
- **3컬럼(내정|군사|주막) 동시 표시 폐기** — 겹침의 직접 원인이며 KOEI 어느 작품에도 없다.
- **주막 패널 삭제** — 초빙은 세력 명령이라 지도에 산다(§0). 거점에 두면 1클릭 → 4클릭 퇴보.
- **"내정"·"군사" 카테고리명 삭제** — 건물이 곧 진입점. 한자어는 아들에게 장벽.

### 5.2 건물 → 패널 (한 번에 하나, 우측 도킹)

| 건물(디오라마) | 패널 내용 |
|---|---|
| 🏪 시장 | 금 수입 / 크게 만들기(Lv→Lv+1) |
| 🌾 농지 | 식량 수입 / 크게 만들기 |
| ⚔️ 병영 | 부대 편성·출진 / 크게 만들기 (※ 징병 자체는 지도에도 유지 — P-3) |
| 📖 학당 | 기술 / 크게 만들기 |
| 🧱 성벽 | 방어력 / 크게 만들기 |
| ⚓ 항구 | 이동·교역 / 크게 만들기 (해안 거점만) |
| 🚪 성문 | 지도로 나가기 |

- 진입: 지도에서 거점 선택 → `[거점 들어가기]`. 복귀: 성문 클릭 / ESC(이미 동작).
- **패널 미오픈 시 디오라마 전체가 보인다** — 지금처럼 하단을 패널이 다 덮지 않는다.
- 건물 hover 시 이름 툴팁 + 하이라이트(클릭 가능함을 알림).

### 5.3 지도에 남는 것 (고빈도 — P-3)
선택 대상 패널의 `[징병 10] [징병 50] [시장 건설] [농지 건설] [부대 이동] [부대 공격]` **유지**. 거점 화면은 증축·편성 등 저빈도용.

## 6. 레이아웃 (1280×720 기준, 겹침 0)

| 영역 | 내용 |
|---|---|
| 상단 (y 0–40) | 자원 바 + 현재 차례 (지도·거점 공통, 앵커 불변) |
| 좌상 (y 44–) | 「이번 달에 한 일」 로그 |
| 우측 (x 980–) | 선택 대상 패널 **또는** 건물 패널 (동시 1개) |
| 우하단 | **턴 종료 단독** |
| 하단 중앙 | 명령 안내줄 (거점에서는 숨김) |
| 중앙 | 모달 (리포트·전투 결과·확인) — 입력 독점 + 딤 |

**이벤트 로그는 Canvas HUD 가 아니라 알림 스택으로**: 최근 3줄만 우상단에 3초 떠 있다 사라지고, 전문은 [이력] 패널.
※ 현재 로그·도시명 라벨은 `WCHUD::DrawHUD` 의 **Canvas** 이며 `UiInCity()` 가드가 없어 거점 패널을 뚫고 그린다 — 이것이 사용자가 본 겹침이다.

## 9. 하지 않기로 한 것 (근거 있는 배제)

- **페이즈 7칩 레일** — 서버가 원자 처리라 관측 불가, 가짜 애니메이션이 된다.
- **핫시트 정보 차단** — 스펙 §1.2 [MUST] 시야 공유·§2.7 같이 보는 화면 위반. 이 게임은 협동이다.
- **"남은 기회" 체크리스트** — 행동력이 없어 비지 않는다(§3.1).
- **우클릭 = 뒤로(전역)** — 우클릭 드래그는 이미 카메라 회전. 필요 시 탭/드래그 분리로만.
- **Lyra 4레이어 재작성** — 클릭 사망 회귀 위험.
- **AI 턴 카메라 추적** — Total War 의 검증된 실패.
