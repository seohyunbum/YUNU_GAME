## 3. 단계 계획

1. **DamageCalculator** (순수 함수) + 단위 테스트 — 상성·지형 보정 데미지, 정수 스케일. (첫 착수)
2. **Battle·BattleUnit + CombatManager(자동 계산)** — 양측 전투력 → 결과, combat 스트림 variance. 무혈 점령을 전투 점령으로 확장.
3. **SkillSystem + EffectType 해석기** — 게이지·발동, aoe_damage·buff·shield·heal·summon. no-op 게이트.
4. **해상전(풍향·조류)·상륙전(-25% 디버프)** — 데미지 공식 확장.
5. **DiplomacyManager** — 동맹·시야공유·자원지원·공동전투.
6. **AIController** — 규칙 기반, 배치 시뮬(AI 100판).
7. **EventBus** — 전투·스킬 이벤트 발행, 콘솔 로그 표현. Phase 3 오라클의 이벤트 시퀀스 기반.

## 5. 미해결 — 진행 중 결정

1. **데미지 공식 구체 형태**: base = atk × 상성 × 지형 × (병력/기준) ± variance? 구체 계수는 DamageCalculator 착수 시 확정 + 배치 시뮬로 밸런스. 정수 스케일 반올림 방향(내림).
2. **전투 단위**: 부대(Army) 전체 vs 병종별 스택. Phase 2 초기는 부대 총 전투력(자동 계산), 병종별 상성은 구성 가중 평균으로 시작.
3. **variance 폭**: combat 스트림 난수 범위(±% permyriad). Phase 2 초기값 후 배치 시뮬 튜닝.
